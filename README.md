# sign

דף חתימה קצר: פותחים לינק, חותמים באצבע, החתימה מוטמעת ב-PDF **במכשיר של החותם**,
ואז שיתוף בוואטסאפ/מייל, צפייה או הורדה. אין שרת ואין העלאה לשום מקום.

המסמכים תחת `docs/` **מוצפנים** (AES-GCM). מפתח הפענוח נוסע ב-fragment של הלינק
(`#k=...`), שלא נשלח לשרת ולא מופיע בריפו - כלומר גם שהריפו ציבורי, המסמכים לא קריאים
בלי הלינק המלא.

נבנה ומתוחזק מ-`Claude\files\contracts\quick-sign\` (publish.py). לא לערוך כאן ידנית.
